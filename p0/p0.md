## Resource 1: CalorieNinjas

**What it provides** (1–2 sentences):
CalorieNinjas provides nutrition and calorie data for foods that are entered in.
**Docs link:**
https://calorieninjas.com/api
**Access:** API key needed? Rate limits? Cost? (write "none" if none)
It needs an API key, the limits are based on plan, free has 10,000 calls a month, novice has 100,000 calls a month, startup has 500,000 calls a month, and business has 2,000,000 a month. The pricing is $0 for free, $8 a month for novice, $20 a month for startups, and $49 a month for business.

## Resource 2: Eventbrite

**What it provides** (1–2 sentences):
Eventbrite is a service that helps people find and look up events. The API only lets you find public events though. 
**Docs link:**
https://www.eventbrite.com/platform/new/api/
**Access:** API key needed? Rate limits? Cost? (write "none" if none)
Yes, an API key is needed. The limits are 48,000 calls a day and 2,000 calls an hour. The cost is free (none).
