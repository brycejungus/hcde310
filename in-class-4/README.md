# Class 4 in-class exercise (pairs, AI: Tutor)

Work in pairs. Follow `predictions.md`:

1. **Part 1: Predict.** Read the five snippets in `exercise.py`. **Don't run anything yet.** Write your guesses.
2. **Part 2: Run.** Run `python3 exercise.py`, fix one snippet at a time, and write what actually happened. Then run `python3 check.py` until it says ✓.
3. **Part 3: Tutor practice.** Pick one snippet and try it with your tutor.
4. **Submit independently:** each of you commits and pushes your own copy, and submits your own **commit link** on Canvas **by midnight tonight**. Name your collaborator in `predictions.md`.

Graded on completion. Didn't get a ✓? Push what you have with a note saying where you got stuck; that still counts.
